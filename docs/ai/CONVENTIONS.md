# Конвенции

## Работа с AI-memory
- Перед началом любой задачи читать все файлы в `docs/ai/`
- Любые изменения в проекте сопровождать обновлением `docs/ai/CURRENT_STATE.md`
- Архитектурные решения фиксировать в `docs/ai/DECISIONS.md`
- После завершения задачи добавлять краткую запись в `docs/ai/CHANGELOG_AI.md`
- Не сохранять в memory логи, stacktrace, временные рассуждения и промежуточные гипотезы

## Подход к изменениям
- Работать минимально инвазивно
- Не ломать существующий рабочий функционал без явного запроса
- Не делать массовые рефакторинги без необходимости

## Язык и аудитория
- Продукт ориентирован на пенсионеров России
- При проектировании интерфейсов учитывать простоту, читаемость и низкий порог освоения
