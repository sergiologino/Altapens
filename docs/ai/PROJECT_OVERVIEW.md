# AltaPens

## Назначение
AltaPens — цифровой продукт для заботы о пожилых людях в России. Проект должен помогать пенсионерам и их близким решать ежедневные задачи, связанные с поддержкой, коммуникацией и удобным доступом к сервисам.

## Состав проекта
- Backend
- Frontend-приложение
- Landing page
