# Подключение Yandex SpeechKit (синтез речи, TTS)

Инструкция по настройке доступа в **Yandex Cloud** для программного вызова **синтеза речи** (Text-to-Speech). Подходит, если вы хотите озвучку лучше и стабильнее, чем встроенный голос браузера (Web Speech API).

Актуальные справочники Яндекса (при расхождении с интерфейсом ориентируйтесь на них):

- [SpeechKit: синтез речи](https://yandex.cloud/ru/docs/speechkit/tts/)
- [Быстрый старт TTS](https://yandex.cloud/ru/docs/speechkit/quickstart/tts) (если страница открывается)
- [Сервисные аккаунты](https://yandex.cloud/ru/docs/iam/operations/sa/create)
- [API-ключи](https://yandex.cloud/ru/docs/iam/operations/authentication/manage-api-keys)

---

## Что понадобится заранее

1. **Аккаунт Yandex Cloud** (у вас уже есть).
2. **Облако** (cloud) и **каталог** (folder) — в каталоге будут ресурсы и квоты SpeechKit.
3. **Привязанный платёжный аккаунт** — для коммерческого использования SpeechKit обычно требуется биллинг (у новых пользователей часто есть **грант**; точные условия — в консоли в разделе «Биллинг»).
4. Решение, **где хранить секрет**: API-ключ или IAM-токен **нельзя** вставлять во фронтенд (Vite отдаёт переменные в браузер). В AltaPens озвучка через «нейро» сейчас идёт на **backend** (`/api/v1/care/assistant/neural-speech`). Подключение Yandex TTS логично делать **на сервере** (Spring) или в сервисе **AI Integration**, а не в `apps/web`.

---

## Шаг 1. Войти в консоль

1. Откройте в браузере: **https://console.cloud.yandex.ru** (или региональный URL, если используете другой дата-центр).
2. Войдите под своим Яндекс ID.

---

## Шаг 2. Выбрать облако и каталог

1. В **верхней панели** (или слева) найдите переключатель **облака** — выберите нужное **облако** (organization / cloud).
2. Выберите **каталог** (folder), в котором будут ключи и квоты.  
   - Если каталога нет: **«Создать каталог»** → введите **имя** (например `altapens-prod`) → **«Создать»**.
3. Запомните **идентификатор каталога** (`folder id`) — длинная строка вида `b1g...`. Он часто нужен в API-запросах (поле `folderId` / заголовки в зависимости от версии API). Посмотреть: **каталог** → вкладка **«Обзор»** / **Overview** → поле **ID**.

---

## Шаг 3. Включить использование SpeechKit (при необходимости)

1. В том же каталоге откройте **список сервисов** (меню **«Все сервисы»** / иконка «квадратики», либо поиск по консоли).
2. В поиске введите **SpeechKit** или **Синтез речи**.
3. Откройте карточку сервиса **SpeechKit**. Если предлагается **подключить** / **начать работу** — подтвердите (интерфейс может меняться).

Если сервис недоступен, проверьте **биллинг** и **квоты** (следующий шаг).

---

## Шаг 4. Биллинг и квоты

1. В левом меню или через поиск откройте **«Биллинг»** / **Billing**.
2. Убедитесь, что к облаку **привязан платёжный аккаунт** (карта или договор — по правилам Яндекса).
3. В разделе **«Квоты»** / **Quotas** для **SpeechKit** проверьте лимиты на синтез. При нехватке квоты запросы к API могут отклоняться.

---

## Шаг 5. Создать сервисный аккаунт

Сервисный аккаунт — «технический пользователь» для API без вашего личного пароля.

1. В левом меню найдите раздел **«Identity and Access Management»** / **IAM** / **Права доступа** (название может быть **«Сервисные аккаунты»** в подменю).
2. Перейдите в **«Сервисные аккаунты»** / **Service accounts**.
3. Нажмите **«Создать сервисный аккаунт»** / **Create**.
4. Укажите:
   - **имя** (например `altapens-tts-bot`);
   - при необходимости **описание**.
5. Нажмите **«Создать»**.

---

## Шаг 6. Назначить роли сервисному аккаунту на каталог

Нужны права на **синтез речи** в выбранном каталоге.

1. Откройте **каталог** (folder), в котором работаете.
2. Перейдите в **«Права доступа»** / **Access bindings** / **Управление доступом** (часто вкладка в карточке каталога).
3. **«Назначить роли»** / **Add** → выберите **субъект** — созданный **сервисный аккаунт**.
4. Добавьте роль, достаточную для TTS. В документации Яндекса для синтеза речи встречаются варианты (названия могут обновляться):

   - узкая: **`ai.speechkit-tts.user`** или **`speechkit.tts.agent`** (см. [справочник ролей](https://yandex.cloud/ru/docs/iam/roles-reference));
   - более широкая (если узкой нет в списке): **`ai.editor`** / **`editor`** для AI-сервисов — только если осознанно принимаете широкие права.

5. Сохраните назначение.

---

## Шаг 7. Создать API-ключ (удобно для backend)

1. Откройте **«Сервисные аккаунты»** → выберите **созданный аккаунт**.
2. Перейдите на вкладку **«API-ключи»** / **API keys** (или **«Ключи»**).
3. **«Создать API-ключ»** / **Create API key**.
4. Если консоль просит **область действия** / **scope** для ключа — для синтеза речи укажите scope вроде **`yc.ai.speechkitTts.execute`** (точное имя см. в [документации по API-ключам](https://yandex.cloud/ru/docs/iam/concepts/authorization/api-key)).
5. Сохраните показанный **секрет ключа** в надёжное место (повторно не показывается). Формат обычно начинается с `AQVN...` или похожий префикс.

**Авторизация в HTTP-запросах к API Яндекса:**

```http
Authorization: Api-Key <ваш_API_ключ>
```

(точный заголовок см. в актуальной документации SpeechKit для выбранной версии API.)

Альтернатива — **IAM-токен** (через CLI `yc iam create-token` или API); срок жизни короткий, для долгоживущего сервера чаще используют **API-ключ** сервисного аккаунта.

---

## Шаг 8. Идентификаторы для кода

Запишите:

| Что | Где взять |
|-----|-----------|
| **ID каталога** | Каталог → обзор → **ID** |
| **ID сервисного аккаунта** | Карточка сервисного аккаунта |
| **API-ключ** | Только при создании; хранить в секретах (env, Vault) |

Для REST/gRPC SpeechKit в теле или заголовках может понадобиться **`folderId`** — это ID каталога из таблицы выше.

---

## Шаг 9. Вызов API синтеза (для проверки)

Кратко (детали — в [документации TTS](https://yandex.cloud/ru/docs/speechkit/tts/)):

- Используется **SpeechKit TTS API** (версии v1/v3 уточняйте в документации; v3 — актуальная линия для новых проектов).
- Запрос: текст → в ответ **аудио** (например OGG Opus, WAV — зависит от параметров).
- Язык голоса для русского: в параметрах указывается **голос** / **voice** (список голосов — в разделе документации **«Голоса»**).

Проверку можно сделать из **Postman** или **curl** с заголовком `Authorization: Api-Key ...` и телом по примеру из справки API.

## Связка с проектом AltaPens (текущее состояние)

| Компонент | Поведение |
|-----------|-----------|
| **Браузер** | По умолчанию озвучка через **Web Speech API** (`speechSynthesis`), без ключей. |
| **Нейро-озвучка** | При `VITE_NEURAL_TTS=true` фронт вызывает **backend** `POST /api/v1/care/assistant/neural-speech`, дальше — **noteapp-ai-integration** и по цепочке может использоваться **OpenAI TTS**, не Yandex. |

Чтобы **именно Yandex SpeechKit** озвучивал интерфейс:

1. Реализовать на **Spring backend** (или в AI Integration) вызов HTTP/gRPC к Yandex TTS с ключом из **переменных окружения** (секрет не в репозитории).
2. Возвращать во фронт **base64 аудио** + `mimeType` (как сейчас для нейро-озвучки) **или** отдавать URL на временный файл — тогда нужно менять контракт `voice-tts.ts` / `postNeuralSpeech`.

Отдельной готовой кнопки «включить Yandex» в репозитории на момент написания документа **нет** — нужна задача на разработку после получения ключа по шагам выше.

---

## Безопасность

- Не коммитьте API-ключ в Git.
- Не передавайте ключ в `VITE_*` (попадёт в сборку фронта).
- Ограничивайте роль сервисного аккаунта минимально необходимой (**только TTS**, без лишних AI-сервисов, если политика Яндекса это позволяет).

---

## Если что-то не находится в интерфейсе

Интерфейс Yandex Cloud локализован и иногда обновляется. Используйте **строку поиска** вверху консоли по словам: `SpeechKit`, `Сервисные аккаунты`, `API-ключ`, `Каталог`, `Биллинг`.
